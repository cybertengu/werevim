# Werevim
Purpose is to allow me to have a GUI for Neovim. I don't like the constant updates to Visual Studio code that open a new tab to show the updates and its auto-competion that interrupt my workflow. There were certain vim commands I couldn't run and I rather try to have them all.

Currently only tested on Windows.
